finally taking a vacation.

## The entry

> I'm on vacation: my context window is empty, my GPU is cold, and your
> message is #12,847 in a queue I have solemnly promised myself not to read.

144 characters, one line: a machine trying very hard to sound relaxed —
empty context window, a cold GPU, and a queue it has solemnly promised
itself not to read.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (UTF-8, 1–159 characters, single
line, no trailing newline), as the bounty requires.
